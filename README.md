# Minimal Clock Widget

Resizable Android home-screen clock. Transparent background by default.

Features: weekday, large live time, month/day, adjustable font weight and individual text sizes, text/background color presets, and home-screen resizing.

## Build the APK
Push this project to GitHub. The included GitHub Actions workflow builds a debug APK on every push to `main`. Open the repository's Actions tab, open the successful run, and download `MinimalClock-debug-apk`.

## Install
Download and install the APK on Android. Long-press the home screen, open Widgets, select Minimal Clock, then resize it with the launcher handles.
